# Privacy Policy Draft

Effective date: 2026-06-20

This privacy policy applies to AudioConvert.

## Data Collection

AudioConvert is designed to process audio files locally on the user's Windows device. The app does not require account sign-in and does not intentionally collect, upload, sell, or share personal data.

## Local Files

The user selects local audio files and output folders. AudioConvert reads the selected files, creates converted output files, and may create temporary files during conversion. Temporary files are used only to complete the local conversion workflow.

## Network Use

AudioConvert does not require network access for its core local conversion features. If future versions add online services, this policy should be updated before release.

## Diagnostics

The app may display local error messages when conversion fails. Unless a user separately sends support information to the publisher, diagnostic information remains on the user's device.

## Third-Party Components

AudioConvert includes third-party runtime components such as FFmpeg and compatibility libraries. These components are used locally to support audio processing.

## User Responsibilities

Users are responsible for ensuring they have the legal right to process the audio files they select. AudioConvert should be used only for lawful personal-file conversion and interoperability.
